# BridgeBot v1 → v2: the fix checklist

v1 is the hackathon build (`master` branch: one `app.py`, ~100 lines). Every row below
exists in code on the `v2` branch and has a test. Run the tests with
`.venv\Scripts\python -m pytest -q`; the slow ones load the real index and models.

| # | v1 problem | Why it mattered | v2 fix | File(s) | Test |
|---|---|---|---|---|---|
| 1 | Knowledge base was one scraped page (`religiondatabase.org/browse`). The site renders with JavaScript, so `WebBaseLoader` got **only "You need to enable JavaScript to run this app"**. | The bot was answering from the LLM's memory while looking like RAG. No citations were possible. | 68 cached sources: 67 English Wikipedia articles plus a rendered copy of the v1 page. Each is saved as markdown with `source_url, title, retrieved_at, country, religion, topic`. Committed, so the demo works offline. | `scripts/build_corpus.py`, `data/corpus/`, `bridgebot/corpus.py` | `tests/test_corpus.py::test_corpus_has_60_plus_sources_with_metadata`, `::test_chunks_carry_citation_metadata` |
| 2 | `RecursiveCharacterTextSplitter(chunk_size=200, overlap=10)`: 200 *characters*. | Chunks were half-sentences with no idea which section they came from. Embeddings of fragments are noisy. | Heading-aware markdown chunking. Chunks are ~400 tokens with ~60 overlap, carry their heading path, and never span two sections. Includes a fix for an overlap-only duplicate-chunk bug found during v2. | `bridgebot/ragcore/chunker.py` | `tests/test_chunker.py::test_chunks_bounded_overlapping_and_tagged`, `::test_no_chunk_is_only_the_previous_overlap` |
| 3 | Vector search only. | Embeddings are weak on exact names ("otoshidama", "Chuseok") and rare terms. | BM25 + dense (bge-small in Chroma), fused with Reciprocal Rank Fusion (k=60). | `ragcore/sparse.py`, `ragcore/dense.py`, `ragcore/fusion.py`, `ragcore/pipeline.py` | `tests/test_fusion.py::test_rrf_scores_match_formula`, `tests/test_pipeline.py::test_hybrid_finds_exact_name` |
| 4 | No reranking, no confidence. | The top 4 vector hits went straight into the prompt, and the bot always answered, even off-topic. | A cross-encoder (`ms-marco-MiniLM-L-6-v2`) reranks the top 20 down to 5. If the best score is below the abstain threshold (0.01, chosen by a sweep), the answer is "My sources don't cover this". | `ragcore/rerank.py`, `ragcore/pipeline.py`, `config.py` | `tests/test_pipeline.py::test_abstains_off_topic` |
| 5 | Follow-ups were searched literally ("what about gifts there?"). | Retrieval for follow-ups found nothing about the place being discussed. | A standalone rewrite plus 2 multi-query variants (fast model). Offline, it appends the last turn's entities. | `ragcore/rewrite.py` | `tests/test_pipeline.py::test_offline_rewrite_resolves_follow_up` (eval: follow-up R@5 0.625 → 1.0) |
| 6 | No citations. | Users couldn't verify anything, and hallucinations were invisible. | Numbered `<source id=n url=...>` blocks treated as data, `[n]` after every claim, and `citation_check`. The answer is regenerated once on failure, then falls back to a cited extractive answer. | `ask.py`, `ragcore/guards.py` | `tests/test_guards.py::test_citation_check`, `::test_citation_after_full_stop_counts` |
| 7 | Guardrails were one prompt line ("if offensive, explain why"). | A prompt is a request, not a control. It can be argued away and can't be tested. | Separate input guards (toxicity → respectful de-escalation reply, prompt injection → refusal, PII masking) and output guards (citation check). | `ragcore/guards.py`, `ask.py` | `tests/test_ask.py::test_offensive_input_deescalated`, `::test_injection_refused`, `tests/test_guards.py::test_toxicity_rules_offline` |
| 8 | A global `chathistory` list. | Every user saw every other user's conversation, and it grew forever. | Per-session history in SQLite (last 6 turns sent), plus a long-term profile (home culture, diet, past trips) used by the agent. | `store.py`, `agent/nodes.py` (`recall_profile`, `update_profile`) | `tests/test_store.py::test_history_isolated_per_session`, `bridgebot/evals/trajectories.py::approve_saves_once_and_updates_profile` |
| 9 | Re-scraped and re-embedded on every start (in-memory store). | Slow start-up, network required. | A persistent Chroma index stores a corpus hash and is only rebuilt when the corpus changes (first build ~70 s, reload ~0.2 s). | `ragcore/dense.py`, `ragcore/pipeline.py::Indexes` | `tests/test_pipeline.py::test_index_reused_when_corpus_unchanged` |
| 10 | No evals. | No way to know whether a change helped or hurt. | A 46-question golden set, Recall@k/MRR/nDCG per config and question type, groundedness, citation coverage, abstain accuracy, safety, cache, agent trajectories, and an eval generator from thumbs-up logs and synthetic questions. | `ragcore/evals.py`, `bridgebot/evals/*` | `tests/test_evals.py::test_metrics`, `tests/test_ask.py::test_feedback_becomes_eval_candidate` |
| 11 | No caching. | Repeat questions paid full latency and cost. | A semantic cache in SQLite, keyed on embedding + entities + corpus hash, threshold 0.92. | `ragcore/cache.py`, `ask.py` | `tests/test_cache.py::test_hit_miss_and_keying` (eval: paraphrase hit at similarity 0.978, about 10x faster than a miss) |
| 12 | Q&A only. | The real job is "prepare me for this meeting", not single questions. | Brief-me LangGraph agent: calendar tool, profile memory, capped research plan, cited draft, sensitivity check, and `interrupt()` human review before the only write. | `bridgebot/agent/` | `tests/test_agent.py::test_trajectories` (9 scenarios) |
